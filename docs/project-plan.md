# Project Plan

## Goal

Deliver a credible, weekend-sized portfolio demonstration of senior platform-engineering practices without presenting a toy workflow as production-ready.

## Incremental plan

1. Establish repository governance, architecture boundaries, and decision records.
2. Build and test minimal telemetry services.
3. Package hardened, non-root containers.
4. Define reusable Terraform and isolated environment roots.
5. Create a secure Helm chart and policy validation.
6. Add CI gates and immutable image publishing.
7. Add Argo CD desired state and controlled promotion.
8. Demonstrate observability, rollback, troubleshooting, cleanup, and production-readiness review.

## Scope controls

Prefer a small end-to-end path with strong evidence over broad unfinished features. Defer multi-region, complex streaming, and enterprise organizational automation to documented production improvements unless time remains.
